## 남은 제한

- 삼성 fallback 17,169건에는 원문 절단, 계수/닫힘 문구 부재, F55/F127 길이 정보 불일치·마스킹 등이 있습니다. 모든 거래가 상세 ok라고 주장하지 않습니다.
- 전체 error 111건: BC IC 구형 헤더 미지원 42, 국민 MS 헤더 부재 6, 전문 wrapper 없는 진단/조각 63. error는 파서가 검증하지 못했다는 뜻이며 거래 자체가 비정상이라는 단정이 아닙니다.
- BC MS 5,776건의 ok는 BCB/BCA/EPT 고정 레코드의 표식·방향·길이 검증입니다. 내부 업무 필드의 별도 규격이 없어 상세 승인 필드 검증은 포함하지 않습니다.

- 현대 MS F90은 취소전문 original data 정의 확인이 필요한 blocked 항목입니다. 미관측 필드·새 포맷은 검증 완료로 간주하지 않습니다.
- 실제 운영 Filebeat/Elasticsearch에 연결한 결과는 아닙니다. CP949 호환 디코딩과 실제 Logstash 실행으로 검증했습니다.

## 운영 최적화

JSON 읽기·검증·정규식 및 프로필 컴파일은 register에서 한 번 수행하고 공유 데이터를 freeze합니다. 이벤트별 파일/네트워크 I/O를 추가하지 않았습니다. 새 처리는 경계와 길이를 확인하는 단계이며 카드사별 필드 규격을 중복 복사하지 않았습니다. 기본 minimal 출력과 기존 분류 태그를 유지합니다. 운영 TPS나 지연 개선 수치를 측정했다고 주장하지 않습니다.
